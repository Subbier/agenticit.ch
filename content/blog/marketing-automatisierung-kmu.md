> **Marketing-Automatisierung verbindet wiederkehrende Arbeitsschritte vom ersten Interesse bis zur nächsten verantwortlichen Person.** Ihr Nutzen entsteht dort, wo heute Daten kopiert, Anfragen gesucht oder Aufgaben vergessen werden. Ein zusätzlicher Tool-Vertrag löst diese Übergaben noch nicht.

## Welcher Ablauf bringt uns zuerst weiter?

Nehmen Sie eine typische Anfrage Ihres Betriebs. Woher kommt sie? Welche Angaben fehlen? Wer sieht sie als Erstes und wer übernimmt danach? Markieren Sie jeden Schritt, bei dem eine Person dieselben Informationen nochmals erfasst oder nach dem Stand fragen muss.

Beginnen Sie bei einer solchen Lücke. [Zoho beschreibt Workflows als Verbindung von Auslösern, Bedingungen und Aktionen](https://help.zoho.com/portal/en/kb/crm/automate-business-processes/workflows/articles/configuring-workflow-rules). Die folgende Auswahl überträgt dieses Prinzip auf den Alltag von Beratung und Verkauf. Sie ist ein Planungsmodell, keine Aussage über bereits eingerichtete Kundenkonten.

## 1. Aus einer Kampagne einen passenden Einstieg machen

**Auslöser:** Ein Interessent öffnet die Zielseite Ihrer Kampagne.

Die Seite beantwortet genau das versprochene Anliegen. Für ein Beratungsteam kann das ein kurzer Check sein, für einen Dienstleister eine brauchbare Entscheidungsvorlage. Das Ergebnis soll bereits helfen, bevor jemand seine Kontaktdaten angibt.

**Praktischer Start:** Eine Zielgruppe, ein Problem und ein passender nächster Schritt. Nutzen Sie unseren [Leitfaden zur Neukundengewinnung](/blog/neukundengewinnung-kmu-schweiz), um Angebot und Kanal festzuhalten. Eine erfolgreiche Anzeige allein beweist noch keinen gewonnenen Kunden.

## 2. Eine Anfrage mit ihrem Anliegen übergeben

**Auslöser:** Der Besucher sendet ausdrücklich eine Kontaktanfrage.

Neben den erforderlichen Kontaktdaten braucht das Team den Zusammenhang: Welche Leistung interessiert die Person? Welches Anliegen hat sie beschrieben? Welcher Kontaktkanal wurde gewünscht? Ein freier Text kann durch KI zusammengefasst werden, ohne die Originalangabe zu ersetzen.

**Prüffrage:** Kommen die vereinbarten Angaben im richtigen CRM an? Testen Sie auch fehlende Angaben und einen ausgefallenen Übergabeweg. Ein Formular mit einer hübschen Bestätigung ist noch kein Empfangsnachweis.

## 3. Eine zuständige Person und Vertretung bestimmen

**Auslöser:** Eine neue oder ergänzte Anfrage trifft ein.

Ordnen Sie sie nach nachvollziehbaren Kriterien zu, etwa Anliegen oder vereinbartem Zuständigkeitsbereich. Falls die zuständige Person fehlt, braucht es eine Vertretung. Eine interne Aufgabe enthält den Anlass und den nächsten zu prüfenden Schritt.

**Praktischer Start:** Ein Eingangskanal, ein Team und eine sichtbare Übernahme. Für viele Betriebe ist diese klare Regel hilfreicher als ein aufwendiger, noch unbelegter KI-Score.

## 4. Nachfassen vorbereiten, ohne wahllos Nachrichten zu versenden

**Auslöser:** Ein vereinbarter nächster Schritt ist offen.

Die zuständige Person erhält eine Erinnerung mit dem bisherigen Kontext. KI kann einen passenden Entwurf vorbereiten. Versand und geschäftliche Empfehlung werden von einem Menschen freigegeben. Eine bereits erfolgte Antwort oder eine Abmeldung muss den vorgesehenen Ablauf stoppen.

**Prüffrage:** Was verhindert eine zweite Nachricht, wenn jemand inzwischen geantwortet hat? Regeln Sie das vor dem Start. Ein heruntergeladenes Arbeitsblatt ist kein Auftrag für eine automatische Kontaktserie.

## 5. Von der Anfrage bis zum tatsächlichen Ergebnis lernen

**Auslöser:** Das Team dokumentiert den nächsten bestätigten Stand.

Trennen Sie eingegangene Anfragen, passende Kontakte, geführte Gespräche und gewonnene Aufträge. So erkennen Sie, ob eine Quelle nur viele Formulare oder tatsächlich passende Gespräche bringt. [Google Ads unterstützt die Übermittlung späterer Ergebnisse](https://developers.google.com/google-ads/api/docs/conversions/upload-offline); deren Einrichtung, Einwilligung und Datenqualität müssen konkret geprüft werden.

**Praktischer Start:** Legen Sie mit dem Team fest, was «qualifiziert» bedeutet und wer den Stand pflegt. Ein Klick, ein Formularstart und ein Auftrag sind unterschiedliche Ereignisse.

## Wo hilft KI und wo reicht eine Regel?

| Aufgabe                                       | Passender erster Ansatz                        |
| --------------------------------------------- | ---------------------------------------------- |
| Ein Formularfeld ins CRM übernehmen           | Geprüfte Feldzuordnung                         |
| Eine Zuständigkeit nach festem Bereich wählen | Nachvollziehbare Regel mit Vertretung          |
| Eine freie Anfrage zusammenfassen             | KI mit Originaltext und menschlicher Prüfung   |
| Eine persönliche Rückmeldung vorbereiten      | Entwurf mit Freigabe vor Versand               |
| Einen Auftrag als Ergebnis zählen             | Bestätigter Geschäftsstatus aus dem Zielsystem |

## Wie beginnen wir ohne grosses Umbauprojekt?

Halten Sie für einen Ablauf fünf Dinge fest: **Auslöser, benötigte Angaben, verantwortliche Person, erlaubte Aktion und Fehlerweg.** Beispiel: Eine Beratungsanfrage geht ein, ihr Anliegen wird übernommen, eine Person erhält die Prüfaufgabe; scheitert die Übergabe, bleibt der Fehler für eine zuständige Person sichtbar.

Prüfen Sie danach einen vollständigen Fall, fehlende Angaben, einen wiederholten Eingang und eine ausgefallene Verbindung. Den detaillierten [Anfrage-CRM-Prüfplan](/blog/ki-automatisierung-vertrieb) können Sie für diese Abnahme nutzen.
